# 有戏｜让你的想法，一步步有戏

**有戏是一款面向早期创业探索者的 AI 辅助决策产品：从你的经历和资源出发，把模糊想法变成可以验证的行动，再依据反馈判断下一步。**

## 产品定位手册

### 为谁设计

有技能、行业经历或初步创业念头，但还没确定具体方向的人。你可能想尝试副业、把擅长的事变成服务，或探索一个小生意，却不知道自己适合做什么、该先验证什么、值不值得继续投入。

### 解决什么问题

| 用户遇到的问题 | 有戏如何帮助 |
| --- | --- |
| 想创业，但方向模糊 | AI 结合个人经历、能力、时间和预算，通过对话协助聚焦方向 |
| 有点子，却不知道判断依据 | 从能力匹配、需求、差异化、收入与成本、可行性、风险六个维度分析，列出依据与未知 |
| 看了很多分析，还是不知道做什么 | 把关键假设转成验证清单，区分公开资料研究与需要本人完成的客户、交付验证 |
| 收集了反馈，却难以作出决定 | 综合已有资料与验证记录，给出搁置、补充验证或小范围落地的建议及下一步 |
| 同时探索多个想法，记录容易混乱 | 每个想法有独立档案，显示阶段进度，可以保存、切换和继续 |

### 用户如何走完一次探索

**个人资料 → 三轮思考对话 → 想法摘要 → 六维分析与验证任务 → 记录真实反馈 → 最终评估。**

1. **认识自己**：上传简历等资料或填写介绍，由 AI 解析成可修改、可确认的个人画像。
2. **聚焦想法**：AI 根据背景主动提问、建议方向，三轮对话后形成摘要；用户可以继续补充和修改。
3. **找出需要验证的事**：分析想法的价值与不确定性，生成具体任务；配置检索能力后，AI 可收集公开来源与摘录。
4. **带回现实证据**：用户记录客户原话、行为、成本、试做结果和来源。公开检索结果需要核对，现实验证仍由用户完成。
5. **决定下一步**：AI 综合上下文生成报告，说明建议、证据缺口与后续行动。用户可以搁置、继续验证或开始小规模尝试，之后仍可回到档案继续。

首页提供新想法入口与最近记录；个人档案展示各想法推进到了哪个阶段。一个想法内部保持「资料 / 对话 / 验证 / 评估」四个阶段，减少页面切换负担。

### 一个典型使用场景

> 以下为虚构示例，用于说明流程，并非真实用户研究成果。

一位擅长摄影、每周有少量空闲时间的人，想探索副业。有戏结合他的经历，帮助聚焦“为附近小餐馆提供菜品摄影服务”，随后列出要验证的问题：店主是否需要、是否愿意付费、单次拍摄与修图耗时多少。用户访谈店主、尝试交付并记录反馈后，再根据证据判断是否值得做一个小规模试点；证据不足时则继续验证。

### 产品的核心价值与边界

有戏把 **个人背景、想法讨论、验证行动和决策依据** 保存在同一条探索流程中，帮助用户回答：“结合我的条件，现在最值得验证什么？”

AI 负责梳理、研究辅助与综合分析；用户确认事实、带回现实证据并作出决定。报告保留不确定性，不提供创业成功率或收入保证。

目前是 **可本地运行的产品原型**：已接入真实 DeepSeek 调用，支持本机档案保存；公开检索需要对应依赖或服务配置。目标用户与痛点仍是设计假设，尚未经过充分真实用户研究。跨新想法复用个人资料仍待完善，当前不能承诺一次上传后所有新项目自动沿用。

详细页面与交互设计见 [产品需求与实现交接](docs/product-spec.md)（早期需求稿，包含尚未完成的设计目标）；实际运行能力与限制见下文。

## 启动

需要 Python 3.10+。macOS 本机可双击 `start.command`，或在工程目录运行：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python server.py
```

打开 http://127.0.0.1:8765 ，首次使用在页面粘贴自己的 DeepSeek API Key，本地服务会写入 `.env`（也可复制 `.env.example` 为 `.env` 手动填写后再启动）。不能再直接双击 index.html：真实AI需要本地服务保管密钥。

若模型调用报 `SSL: CERTIFICATE_VERIFY_FAILED`，说明当前 Python 缺少根证书：先确认已安装 requirements.txt（内含 certifi，服务会自动使用）；仍失败时运行 Python 安装目录下的「Install Certificates.command」。

本机启动脚本也会在没有虚拟环境时尝试已安装的 Codex Python 运行时；其他电脑按上面的标准步骤安装即可。浏览器需要支持 fetch、crypto.randomUUID、structuredClone 的现代版本。

## 已接入

- 首次运行的 Key 配置页：页面粘贴即写入本机 `.env`，仓库与页面均不包含任何密钥。
- DeepSeek 解析个人介绍或提取后的文件文本。
- 主动引导的三轮对话：开场点出画像亮点并给方向建议；用户不确定时给出可点选的候选方向，随时可换；方向未定时摘要会主动初拟一个用于迭代。
- 六维分析；验证任务区分「需要你亲自验证」与「AI 公开检索」。
- AI 公开检索（可选）：分析后自动为公开资料任务检索真实来源与摘录（Tavily 或 DuckDuckGo 自动检测）；结果标注未经人工核验。
- 填写真实发现、原话和来源；模型综合全部上下文生成三类建议，下一步包含本周可执行的第一步。
- 多想法切换、草稿保存、本地服务端存储、报告历史与导出。
- 文字型 PDF、DOCX、TXT/MD/CSV/JSON 文件提取；原始文件不保存，只保存提取文本。

## 明确的限制

**AI 公开检索为可选能力，且结果未经人工核验。** 默认自动检测：安装 ddgs（已列入 requirements.txt）或配置 `TAVILY_API_KEY` 后，分析产生的公开资料任务会自动检索并登记真实来源与摘录；两者都不可用时任务如实标注「待检索」，需用户自行查证。检索结果为机器抓取，DeepSeek 的语言回答不是网页搜索结果，链接也不代表已核验。

不支持扫描件OCR、旧DOC格式、云同步、多人协同、账户管理或公共部署。当前服务仅绑定 `127.0.0.1`，设计为同一台机器上的单用户应用；请不要用多个标签同时编辑同一份数据。

这不是从 REDcowork 取回的原始全栈工程。它以用户提供的三文件静态版为基础，完成了本地服务及真实AI接入。当前功能仍需目标用户验证；模型建议不是创业成功保证。

## 密钥、数据与费用

- 密钥只在根目录 `.env`（首次打开页面时粘贴保存，或手动编辑），浏览器通过本机接口调用；静态文件服务采用允许列表，不会提供 `.env`、源码或数据文件。
- 文件/个人介绍在点击AI按钮后会发送给DeepSeek处理；文件提取本身在本机进行。
- 项目存于 `data/projects.json`，上次写入备份为 `data/projects.backup.json`，浏览器另有草稿副本。定期点击导出备份。
- `.env`、`data/`、虚拟环境均被 `.gitignore` 排除。不要把简历原件、密钥、个人档案或导出的真实用户备份提交到仓库。
- 默认使用 `deepseek-flash` 非思考模式，单次输入最多24000字符、输出最多2600 tokens；请求次数默认不限（`.env` 中 `DAILY_REQUEST_LIMIT` 设为正数可加上限），失败尝试也计数，不自动重试。模型与检索用量记录在 `data/usage.json`。
- 上述限制用于控制调用量，**不是人民币费用上限**。余额和实际费用以 DeepSeek 控制台为准。检索另受 `SEARCH_DAILY_LIMIT`（默认40次/日，0=不限）约束；Tavily 有免费额度，DuckDuckGo（ddgs）检索免费。
- 本地缓存同一请求ID的成功结果，避免短时重复调用；缓存不跨服务重启。

## 工程结构

```text
public/       页面、样式和前端逻辑
server.py     本地HTTP服务、DeepSeek接口、文件提取与存储
requirements.txt
.env.example  配置模板，不含密钥
start.command 本机启动入口
tests/        不消耗API额度的契约测试
docs/         产品规格与检查记录
```

运行测试：`python -m unittest discover -s tests -v`。测试不调用真实模型。

## GitHub 提交

这是带本地后端的源码项目，GitHub 仓库可供评审克隆后运行。**GitHub Pages 只能托管静态文件，不能运行 server.py，也不能安全保管此密钥。**要提供无需本机启动的在线AI作品，需要再部署具备服务端运行和秘密管理的环境，并增加访问控制与用量限制；本次未进行发布。

提交前确认 `.env` 与 `data/` 均被忽略，再提交源码和运行说明。不要上传整个文件夹的未经筛选压缩包。
